# ทฤษฎีระบบ IoT เบื้องต้น

## IoT คืออะไร

IoT หรือ Internet of Things คือระบบที่อุปกรณ์อิเล็กทรอนิกส์สามารถรับข้อมูลจากสภาพแวดล้อม ประมวลผล และส่งข้อมูลผ่านเครือข่ายเพื่อให้เกิดการติดตามสถานะ การวิเคราะห์ หรือการควบคุมอัตโนมัติ

## องค์ประกอบหลักของระบบ IoT

1. อุปกรณ์ปลายทาง เช่น sensor, actuator, controller
2. ช่องทางสื่อสาร เช่น Wi-Fi, Ethernet, RS485, LoRa หรือ MQTT over TCP/IP
3. ระบบรับส่งข้อความและประมวลผล เช่น MQTT broker และ Node-RED
4. ระบบจัดเก็บข้อมูล เช่น InfluxDB
5. ระบบแสดงผลและวิเคราะห์ เช่น Grafana

## เหตุผลที่ใช้ Local IoT Server

- ลดการพึ่งพา cloud ในระบบที่ต้องการทำงานภายในองค์กร
- ลด latency ในการรับส่งข้อมูล
- ควบคุมข้อมูลได้เอง
- เหมาะกับห้องทดลอง โรงงานขนาดเล็ก หรือระบบที่ต้องการความเป็นส่วนตัว

## หลักคิดด้านวิศวกรรม

เมื่อออกแบบระบบ IoT ควรคิดถึงประเด็นต่อไปนี้

- ความน่าเชื่อถือของข้อมูล
- ความหน่วงของระบบ
- การขยายระบบในอนาคต
- ความปลอดภัยของเครือข่ายและบัญชีผู้ใช้
- ความสามารถในการบำรุงรักษา
- การสังเกตสถานะของระบบผ่าน logs และ dashboards

## บทบาทของ stack นี้

ระบบในโครงการนี้ใช้แนวคิดแยกหน้าที่อย่างชัดเจน

- Mosquitto รับผิดชอบเรื่อง message broker
- Node-RED รับผิดชอบ logic และ automation
- InfluxDB รับผิดชอบการเก็บข้อมูลแบบ time-series
- Grafana รับผิดชอบการแสดงผลข้อมูล

## ตัวอย่างการไหลของข้อมูล

```text
Temperature Sensor -> MQTT Topic -> Node-RED -> InfluxDB -> Grafana Dashboard
```

## ประโยชน์ของการแยก service

- ดูแลแต่ละส่วนได้ง่าย
- เปลี่ยนหรืออัปเกรดบริการได้ง่ายขึ้น
- แยกสาเหตุของปัญหาได้สะดวก
- ปรับขนาดแต่ละส่วนได้ตามภาระงาน
