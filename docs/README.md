## โครงสร้างความรู้

- คู่มือการติดตั้ง: ตั้งแต่ Raspberry Pi OS จนถึง Docker Compose
- คู่มือการปฏิบัติการ: การตรวจสอบสถานะ, backup, logs และการดูแลระบบ
- คู่มือใช้งานจริง: hardening, backup, restore และการเตรียมระบบสำหรับ production
- สถาปัตยกรรม: ภาพรวมการไหลของข้อมูลและหน้าที่ของแต่ละ service
- ทฤษฎีพื้นฐาน: MQTT, Node-RED, InfluxDB, Grafana และหลักคิดของระบบ IoT
- ความปลอดภัย: แนวทาง hardening สำหรับการใช้งานจริง
